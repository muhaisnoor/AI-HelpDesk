# AI-HelpDesk

I built an IT Help Desk Assistant using Google Gemini Gems. The assistant helps users troubleshoot common IT problems by asking questions, providing one step at a time, and checking whether the problem was resolved.

I built this project to practice prompt engineering, generative AI, and designing AI tools for real-world business use.

## How It Works

The assistant is designed to:

- Ask one troubleshooting question at a time
- Start with simple and low-risk solutions
- Avoid guessing when information is missing
- Verify whether a solution worked
- Protect sensitive information such as passwords and MFA codes
- Escalate unresolved problems to IT support

## Testing

I tested the Gem with four scenarios:

- Wi-Fi connection problems
- Account/login problems
- Slow computer performance
- VPN connection problems

During testing, I noticed the first version asked users multiple questions at once. I changed the instructions to ask one question at a time and retested the Gem to confirm the improvement.

## What I Learned

This project gave me hands-on practice with Gemini Gems, prompt engineering, AI testing, and IT troubleshooting workflows.
